Behind the system

DSA Concepts

Explore the data structures and algorithms used by ResQ Dispatch.

1. Priority Queue

Emergency requests are ranked by urgency. High-priority cases are served before medium and low-priority cases. If priority is equal, the earlier request goes first (FIFO).

High → Medium → Low\nTie-breaker: arrival order

2. Sorting / Heap Idea

A priority queue can be implemented using a binary heap to efficiently retrieve the most urgent waiting emergency.

Insert request: O(log n)\nPeek highest priority: O(1)\nRemove top: O(log n)

3. Queue for Dispatch History

Dispatch records are appended as events occur and displayed in chronological order, helping review earlier actions.

enqueue(record)\nview history from oldest to newest

4. Greedy Assignment

The simulator assigns the next waiting emergency to an available ambulance. A real deployment would need verified routing, live traffic and emergency-service integration.

Choose top waiting request\nChoose available ambulance\nMark request as dispatched
